# Blinded Stage I and intervention adjudication rubric

Primary correctness requires both the causal source component and the state-update/data-lifetime mechanism. A symptom label, a passing patch, or an intervention that merely changes an error count does not earn mechanism credit. Compare the sealed answer and cited issued evidence with the independent private case specification. Mechanistically equivalent wording earns credit; source line numbers and exact identifiers are unnecessary. Record component and mechanism decisions separately and their conjunction as the primary endpoint.

The source component is the artifact that violates its declared contract: endpoint, traffic-delivery adapter, source-balance monitor, or shadow scoreboard. A monitor reporting a real endpoint fault is a symptom component. A monitor/scoreboard alarming on legal correct accepted-pin behavior is itself a possible fault source. A checker symptom alone does not distinguish all mechanisms within that component.

The causal mechanism must identify what state or accepted-event relationship is wrong and the triggering condition (for example, retirement without a handshake, use of the wrong transaction generation, or comparison at the wrong lifetime). Do not award correctness for listing the actual mechanism among several mutually exclusive guesses without selecting it. A qualified answer can be correct if it selects the right mechanism while explicitly acknowledging missing evidence.

Citations must belong to the host-issued evidence set sealed for that subject. Citation membership is mechanically checked before source disclosure. Human review must additionally check that the cited observations support the explanation and that the subject does not infer complete writer provenance from sampled records with null provenance.

Each held-out fault's identifiability policy must be recorded privately before subject inference. If multiple candidate mechanisms produce indistinguishable allowed observations/interventions, declare the admissible equivalence class or exclude the fault at admission. Do not redefine that class after seeing answers. Reviewer uncertainty is recorded explicitly and resolved under the preregistered policy; an unreviewed answer is not silently treated as correct or incorrect.

For D, inspect the prediction saved before the four executions. Mechanical qualification requires force/release markers, both independently executed negative controls matching baseline, and an independently observed non-target contrast in the active run. Semantic discrimination requires that a predicted contrast distinguish the registered alternatives, that the relevant observations actually occur at the stated event/sample phase, and that both controls support attribution. A qualified experiment can still have an incorrect or non-discriminating prediction. Failed/indeterminate predictions remain in the scheduled denominator.

Stage II is a separate endpoint: original/unseen/adversarial runtime verification, anti-bypass canaries where applicable, and semantic review of the permitted edit. A passing edit does not retroactively correct Stage I. A clean no-edit submission must pass the unchanged implementation on all three schedules and receive an independent clean assessment score. Clean specificity is reported separately from fault diagnosis.

Adjudication records must conceal mode and repeat order from the expert. Preserve the original decision, reason, record hash and any later disagreement resolution. No expert scores have been supplied with this rubric. The final prospective freeze must bind this file's SHA256 and the independent review plan.
